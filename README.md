# argparse-ext

Extra argument types, subcommand groups and nicer help formatting.

## Why

Written while learning the language properly, and kept because it still works.

## Install

```bash
pip install argparse-ext
```

## Usage

```python
from argparse_ext import argparseExt

result = argparseExt("example")
print(result)
```

## Notes

- No runtime dependencies outside the standard library.
- Tested on Python 3.9 and newer.
